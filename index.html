Panduan Google Sheets & Kolum

Susunan tajuk kolum di **Baris 1 Google Sheet** anda:

1. Nama Kolum Google Sheets (Baris 1)

A: Masa Pendaftaran
B: Nama Pelajar
C: No IC
D: Kelas
E: Badan Beruniform
F: Kelab Persatuan
G: Sukan Permainan

2. Google Apps Script Code (Dikemas kini)

Gunakan kod di bawah dalam Extensions -> Apps Script di Google Sheets anda:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  sheet.appendRow([
    new Date(),
    data.nama,
    "'" + data.noIc, // tanda ' elak format nombor automatik hilang
    data.kelas,
    data.badanBeruniform,
    data.kelabPersatuan,
    data.sukanPermainan
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
                       .setMimeType(ContentService.MimeType.JSON);
}
